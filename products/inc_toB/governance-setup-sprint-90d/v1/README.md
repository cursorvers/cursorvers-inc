## ローカルスクリプト

### 容量見積もりスクリプト

現在のシート行数から残容量と月間処理可能件数を推定します。

#### 基本使用方法

```bash
cd spec/local_scripts

# デフォルト設定で実行
python estimate_capacity.py

# パラメータを指定して実行
python estimate_capacity.py --rows 500 --cols 30 --monthly 20

# JSON形式で出力
python estimate_capacity.py --rows 500 --json

# 複数シナリオをシミュレート
python estimate_capacity.py --simulate 100 500 1000 5000 10000
```

#### オプション

| オプション | 説明 | デフォルト |
|-----------|------|----------|
| `--rows`, `-r` | 現在の行数 | 100 |
| `--cols`, `-c` | 列数 | 30 |
| `--monthly`, `-m` | 月間案件数 | 20 |
| `--json`, `-j` | JSON形式で出力 | - |
| `--simulate` | 複数シナリオをシミュレート | - |
